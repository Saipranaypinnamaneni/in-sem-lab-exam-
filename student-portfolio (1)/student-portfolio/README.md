# Student Portfolio Website

A responsive student portfolio built with plain HTML, CSS, and JavaScript. No build tools are required.

## Files
- `index.html` — page content and sections
- `style.css` — colors, layout, and responsive design
- `script.js` — mobile navigation and current year
- `assets/` — optional images and other files

## Customize before publishing
1. Replace `Your Name` and `YN` with your name and initials.
2. Update the About section with your course, college, interests, and goals.
3. Replace the sample project descriptions and add your actual project links.
4. Replace `you@example.com`, `YOUR-USERNAME`, and the LinkedIn link with your own details.
5. Adjust the skill bars to match your current experience.

## Publish with GitHub Pages
1. Upload these files to a GitHub repository named `student-portfolio`.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then click **Save**.
5. Wait a few minutes and refresh the Pages settings. The site URL is usually:
   `https://YOUR-USERNAME.github.io/student-portfolio/`

Make sure `index.html` is in the repository root, not inside another nested folder.
